# Sistema de Gerenciamento de Produtos

Este projeto é uma API desenvolvida com **Node.js** e **Express.js**, com o objetivo de gerenciar produtos/itens, permitindo cadastrar, listar, atualizar e controlar o status de cada item.

O sistema foi desenvolvido como atividade prática da disciplina de Desenvolvimento Web, utilizando conceitos de backend, rotas HTTP, manipulação de dados em memória e validações básicas.

---

## Tecnologias utilizadas

- Node.js
- Express.js
- JavaScript
- Nodemon
- Insomnia/Postman para testes das rotas

---

## Objetivo do projeto

O objetivo principal do projeto é criar uma API simples para gerenciar produtos, permitindo realizar operações básicas como:

- Cadastrar novos produtos;
- Listar produtos cadastrados;
- Buscar produto por ID;
- Atualizar informações de um produto;
- Excluir produtos;
- Validar dados enviados pelo usuário;
- Controlar o status do produto.
