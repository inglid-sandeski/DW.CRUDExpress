# 🛒 CRUD de Produtos - DESENVOLVIMENTO WEB

## 📖 Descrição

Este projeto consiste em uma aplicação web para gerenciamento de produtos, desenvolvida como atividade acadêmica da disciplina de Desenvolvimento Web da Universidade do Estado de Mato Grosso (UNEMAT).

A aplicação implementa as operações básicas de um CRUD (Create, Read, Update e Delete), permitindo o cadastro, consulta, atualização e remoção de produtos por meio de uma interface web integrada a uma API desenvolvida com Node.js e Express.

---

## 🎯 Objetivos

* Aplicar conceitos de desenvolvimento web.
* Implementar uma API REST utilizando Express.
* Praticar operações CRUD.
* Trabalhar com requisições HTTP.
* Desenvolver uma interface amigável para gerenciamento de produtos.

---

## 🚀 Funcionalidades

✅ Cadastrar produtos

✅ Listar produtos cadastrados

✅ Atualizar informações de produtos

✅ Excluir produtos

✅ Comunicação entre Front-end e Back-end

✅ API REST utilizando Express.js

## ⚙️ Instalação

### 1. Clonar o repositório

```bash
git clone https://github.com/inglid-sandeski/DW.CRUDExpress.git
```

### 2. Entrar na pasta do projeto

```bash
cd DW.CRUDExpress
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Executar o projeto

```bash
node server.js
```

ou

```bash
npm start
```
